📖 Reference: How to Find Device ID & Local Key

Tuya Developer Platform Device Discovery

  1. Log in to the Tuya Developer Platform (Project Direct Link) .
  2. Go to Cloud → Devices → All Devices.
  3. Your devices will appear with their Device ID and device details. See documentation: Tuya-Local Device Details Guide (GitHub) .
  4. Region Selection: If devices don’t show, ensure the correct server region is selected (Region: IN / India).
  5. Find Local Key: In Tuya Developer Console, navigate to Cloud → API Explorer → Smart Home Device System → Device Control → Get Device Details, enter your Device ID, and submit to reveal the 16-character local_key.
